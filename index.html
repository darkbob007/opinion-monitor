零基础 10分钟自动采集部署向导

按照以下步骤操作，全自动每日09:00抓取更新

💡 原理说明： 本教程利用 GitHub（全球最大的免费代码托管平台）提供的免费云端服务器，每天早晨 9 点自动唤醒我们提供的一段 Python 代码。代码会自动去抓取海外各大媒体（如美国之音、自由亚洲等）关于预设政治敏感词的公开报道，生成一个名为 opinion_data.json 的文件并自动推送到你的网页。你不需要懂得如何运行代码，只需要复制粘贴！
1

第一步：注册并创建 GitHub 仓库

  1. 访问官网 GitHub.com 并注册一个免费账号。
  2. 登录后，点击网页右上角的“+”号，选择 “New repository”（新建仓库）。
  3. 仓库名称（Repository name）填写：opinion-monitor。
  4. 设置选择“Public”（公开，这样才能启用免费网页展示功能）。
  5. 勾选 “Add a README file”，然后点击最下方的绿色 “Create repository” 按钮创建。
2

第二步：上传这个网页文件

  1. 进入你刚刚创建的仓库页面，点击右上角的 “Add file” 按钮，选择 “Upload files”。
  2. 将你本地电脑上的当前 HTML 网页文件拖拽进去，并改名为：index.html。
  3. 点击最下方的绿色 “Commit changes” 按钮提交保存。
3

第三步：创建自动采集脚本（机器人）

这个脚本会利用 Python 内置库抓取海外各大媒体公开订阅源。你不需要安装 Python，只需在 GitHub 页面上新建一个文件即可：

  1. 在你的 GitHub 仓库主页，点击 “Add file” 按钮，选择 “Create new file”。
  2. 文件名（File name）填写：crawler.py
  3. 在下面的代码框中，粘贴下方我们为你准备好的 Python 采集代码：
# -*- coding: utf-8 -*-
import json
import urllib.request
import xml.etree.ElementTree as ET
from datetime import datetime
import ssl

# 忽略 SSL 证书安全验证，确保能顺利访问境外媒体
ssl._create_default_https_context = ssl._create_unverified_context

# 监控的海外媒体 RSS 公开订阅源（这些由 GitHub 在海外的服务器拉取，因此不受防火墙限制）
FEEDS = [
    {"name": "美国之音 (VOA)", "url": "https://www.voachinese.com/api/z$g_vte_kp", "source": "News"},
    {"name": "自由亚洲电台 (RFA)", "url": "https://www.rfa.org/mandarin/RSS", "source": "News"},
    {"name": "德国之声 (DW)", "url": "https://rss.dw.com/xml/rss-chi-all", "source": "News"}
]

# 监测的关键词红线
KEYWORDS = ["习近平", "Xi Jinping", "中南海", "北京当局", "中国高层"]

def fetch_feed(feed_info):
    articles = []
    try:
        req = urllib.request.Request(
            feed_info["url"], 
            headers={'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64)'}
        )
        with urllib.request.urlopen(req, timeout=15) as response:
            xml_data = response.read()
        
        # 解析 RSS XML 数据
        root = ET.fromstring(xml_data)
        for item in root.findall('.//item'):
            title = item.find('title').text if item.find('title') is not None else ""
            link = item.find('link').text if item.find('link') is not None else ""
            desc = item.find('description').text if item.find('description') is not None else ""
            
            # 判断标题或描述中是否包含我们要监控的敏感词
            content_to_check = (title + desc).lower()
            if any(kw.lower() in content_to_check for kw in KEYWORDS):
                found_kws = [kw for kw in KEYWORDS if kw.lower() in content_to_check]
                articles.append({
                    "title": title,
                    "source": feed_info["source"],
                    "sourceName": feed_info["name"],
                    "time": "今日 09:00", # 标记为统一自动更新时间
                    "url": link,
                    "sentiment": "High" if "习近平" in title else "Medium",
                    "summary": desc[:150] + "..." if len(desc) > 150 else desc,
                    "keywords": list(set(found_kws)) if found_kws else ["政治舆情"]
                })
    except Exception as e:
        print(f"抓取 {feed_info['name']} 失败: {e}")
    return articles

if __name__ == "__main__":
    all_data = []
    for f in FEEDS:
        all_data.extend(fetch_feed(f))
    
    # 过滤出重复的标题，保证数据纯净
    seen_titles = set()
    unique_data = []
    for item in all_data:
        if item["title"] not in seen_titles:
            seen_titles.add(item["title"])
            unique_data.append(item)
            
    # 如果抓取到了数据，分配 ID；如果没抓到，生成安全通报
    if not unique_data:
        unique_data = [{
            "id": 1,
            "title": "今日暂无触发监控红线的新增敏感信息",
            "source": "News",
            "sourceName": "监控中心",
            "time": datetime.now().strftime("%Y-%m-%d %H:%M"),
            "url": "#",
            "sentiment": "Medium",
            "summary": "全网未检索到包含预设政治敏感词的高危负面信息，系统安全平稳运行。",
            "keywords": ["安全运作"]
        }]
    else:
        for i, item in enumerate(unique_data):
            item["id"] = i + 1

    # 导出文件
    with open('opinion_data.json', 'w', encoding='utf-8') as f:
        json.dump(unique_data, f, ensure_ascii=False, indent=4)
    print(f"成功导出 {len(unique_data)} 条敏感信息！")

（注：粘好后，滑动到页面最下方点击绿色“Commit changes”保存该文件。）

第四步：设定每日 9:00 闹钟（自动化配置）

这一步是设置定时任务，让 GitHub 的服务器每天早上 9 点准时起来干活并更新页面：

  1. 在你的仓库页面上，点击 “Add file” -> “Create new file”。
  2. 文件名必须严格输入：.github/workflows/main.yml
  3. （输入前面的文件夹斜杠时，GitHub 会自动转为目录。确保最终路径跟上面一模一样）
  4. 在下方内容区，粘贴我们为你写好的自动运行配置文件：
name: Daily Opinion Auto Update

on:
  schedule:
    # 国际标准时间 (UTC) 01:00，对应北京时间 09:00 (东八区时间)
    - cron: '0 1 * * *'
  workflow_dispatch: # 允许你随时在 GitHub 页面上手动点击运行

jobs:
  build:
    runs-on: ubuntu-latest
    permissions:
      contents: write # 授予写入权限，以便脚本自动将结果写回仓库

    steps:
    - name: Checkout Code
      uses: actions/checkout@v3

    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: '3.9'

    - name: Run Crawler Script
      run: python crawler.py

    - name: Save & Push Changes
      run: |
        git config --global user.name "GitHub Action Bot"
        git config --global user.email "action@github.com"
        git add opinion_data.json
        git commit -m "Auto-updated opinions at 09:00" || exit 0
        git push origin main

（注：粘好后，滑动到页面最下方点击绿色“Commit changes”保存该文件。）

第五步：一键开启免费公共网址

最后一步，让你的仓库变成一个可以随时通过手机或电脑打开访问的在线网址：

  1. 在你的 GitHub 仓库顶部，点击 “Settings”（设置）选项卡。
  2. 在左侧导航栏中，点击 “Pages” 选项。
  3. 在中间的 “Build and deployment” 下找到 Branch，将下拉框的 “None” 更改为 “main”。
  4. 点击右侧的 “Save” 保存按钮。
  5. 等待大约 1 分钟，刷新该页面。你会在上方看到一排绿色的提示语：“Your site is live at...” 后面跟着的就是你的专属全球访问网址！
